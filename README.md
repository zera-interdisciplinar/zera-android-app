# Zera — App Android

Aplicativo Android do **Zera**, sistema de gestão e controle de lixo eletrônico corporativo, desenvolvido inicialmente para o Instituto J&F / JBS. O app é o ponto de entrada operacional do sistema: nele, funcionários e gestores cadastram, classificam e acompanham o ciclo de vida dos equipamentos eletrônicos armazenados, do registro inicial até a destinação final (reuso, aproveitamento de peças ou descarte).

Construído em **Kotlin** com **Jetpack Compose**, seguindo uma arquitetura em camadas (view / viewmodel / model) com um Design System próprio.
